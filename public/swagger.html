Bắt đầu trong 3 bước
  1. Đọc GET /api/products để lấy ID, màu và quy cách thật.
  2. Gọi đăng ký/đăng nhập khách. Swagger tự nhận token cho các yêu cầu tiếp theo.
  3. Gọi báo giá rồi đặt đơn với expectedTotal. Chọn Try it out → Execute để gửi yêu cầu thật.
Khách hàng & quản trị

CustomerBearer: nhập JWT từ API đăng nhập. Token hết hạn sau 24 giờ.

AdminToken: nhập ADMIN_TOKEN từ cấu hình riêng. Hoặc gọi API đăng nhập quản trị để dùng cookie HttpOnly, thời hạn 8 giờ. Swagger tự thêm X-Requested-With: shop-admin khi ghi qua API quản trị.

Token nhập trong trang không lưu sau khi tải lại. Cookie theo thời hạn phiên server.

Đọc phản hồi & xử lý lỗi

200: thành công · 201: đã tạo tài nguyên. Lỗi trả JSON có trường error.

400: dữ liệu không hợp lệ · 401/403: xác thực/quyền · 404: không tìm thấy · 409: xung đột giá/tồn kho/trạng thái · 413: body quá lớn · 429: quá số lần thử.

Ví dụ là dữ liệu minh họa. Thao tác ghi cập nhật dữ liệu thật; thanh toán hiện hỗ trợ COD.
